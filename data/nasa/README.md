# NASA research data landing zone

Intentionally empty of 'downloaded NASA data' until the implementation phase. **Do not fabricate records.** Codex research role will create:

- `source_manifest.json` with verified NASA source IDs, titles, URLs, accessions/retrieval dates, exact source usage and challenge Resources listing flag.
- `curated_evidence.json` with concise source-supported risk context records used by `/about/science` and explanation cards.
- Optional `raw/` snapshots of actual publicly accessible NASA study metadata, with reproducible fetch instructions.

Public sources to investigate: `research/NASA_SOURCES.md`. A source is not automatically eligible merely because it is on nasa.gov; confirm the official challenge Resources tab.
