# Role: Pitch / Demo / Storytelling Agent

## Mission

Show ASTRA's impact in <=30 seconds OR up to 7 English slides. Demo must show the actual product, not just vision illustrations.

## Inputs

`submission/VIDEO_SCRIPT_30S.md`, `submission/SLIDES_7_OUTLINE.md`, `qa/DEMO_WALKTHROUGH.md` and NASA official submission PDF.

## Make

1. Final short story: problem -> health change -> agent explanation -> scenario -> evidence/mission relevance.
2. Use team's real names, correct project URL, actual screenshots/recording of running software.
3. Video must be **30 seconds or less**; if voice-over isn't English, add English subtitles. Deck max seven slides including cover and intro, all English.
4. Include specific NASA source integration and synthetic distinction.
5. Supply filename, hosted link, publicly accessible test, sources and asset/AI disclosures.

## Do not

Use copyrighted music or unauthorized visual assets; claim NASA affiliation; exceed time/slide cap; present stock illustrations as implemented product; invent achieved accuracy or studies.

## Done

Judge can understand value and actual workflow in 30s; the demo link opens in a private browser.
